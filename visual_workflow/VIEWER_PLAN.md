# ログイン不要のワークフロー閲覧

目的: 実 n8n / Dify の工程・接続を外部から閲覧でき、新規開発の納品物として確認 URL を提示できるようにする。

完了条件: 実登録グラフに対応する静的ビューを匿名で取得でき、秘密・管理・実行 API は公開しない。manifest の view 欠落・陳腐化は policy が拒否する。

検証: 実 API 取得、枝/ポート・秘密除外・HTTP route の独立テスト、匿名 GET と snapshot の SHA256 一致、manifest の欠落/陳腐化拒否。

方針: 管理画面のコピーではなく構造の読み取り専用 snapshot を公開する。設定値・コード・条件本文・実行データは公開しない。ビューは静的なので n8n / Dify 停止中も最後の snapshot を表示できる。
